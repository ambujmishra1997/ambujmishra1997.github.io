## Deployment Workflow

```text
Build Portfolio
      ↓
Git Add / Commit
      ↓
Push to GitHub
      ↓
GitHub Repository
      ↓
Settings → Pages
      ↓
Deploy from main / root
      ↓
Live Portfolio Website
```

## GitHub Pages Configuration

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

## Run Locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
